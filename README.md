# Grabit Academy · מדריך עבודה למובילים

מדריך הכשרה אינטראקטיבי, מובייל-first ו-RTL — לחברת ההובלות **Grabit**.
חוויית "יום עבודה אחד" שמלווה את המוביל ממשימה #2048 מתל אביב לחיפה, דרך 4 פרקים: אריזה, פריקה, תקשורת עם לקוח, וסיום.

## 🔗 דמו חי
[פתחו את המדריך](https://merav-taler.github.io/grabit-academy/) · מומלץ לפתוח בטלפון.

## ✨ מה יש בפנים

- **17 מסכים**, כל פרק = סצנה + 2–3 אינטראקציות שונות + סיכום קצר
- **8 סוגי אינטראקציה** (כל אחת מופיעה פעם–פעמיים, לא חוזרים):
  חקירת חדר (hotspots) · גרירת סדר · מבחן ניעור (אודיו) · הליכה בין חדרים · שיבוץ סימונים · התאמה (matching) · טאבי חקירה · תשובה פתוחה
- **משאית התקדמות** שנוסעת מת"א לחיפה לאורך המדריך
- **שעון משימה** שמתקדם מ-08:00 ל-17:00
- **קובץ אחד · ללא תלויות** — HTML + CSS + JS וניל. פותחים את `index.html` בדפדפן וזהו.
- **תמונות אמיתיות** מהאפיון (סצנות חדרים, פריטים, מסקוט הארנב)

## 🗂️ מבנה

```
index.html              ← כל האפליקציה
images/                 ← 77 תמונות מהאפיון המקורי
design-language.md      ← שפה עיצובית להעברה ל-Claude Design / כלים אחרים
```

## 🛠️ הרצה מקומית

פותחים `index.html` בדפדפן. או:

```bash
python3 -m http.server 8000
# ואז: http://localhost:8000
```

## 📐 שפה עיצובית

ראו [`design-language.md`](design-language.md) — פלטה, טיפוגרפיה, רכיבים, מבנה תוכן, ועקרון הגיוון בין סוגי אינטראקציה.
